# 从真实结果构建论文提纲

[分类目录](README.md) · [总目录](../../README.md)

ID：`academic-writing/paper-outline`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `question` | 研究问题 |
| `method` | 已实现方法 |
| `results` | 真实实验摘要 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
question：{{question}}
method：{{method}}
results：{{results}}

先提炼被结果支持的中心主张，再安排每节要回答的问题。将方法设计与对应实验一一连接；跨数据集下降应纳入分析而非隐藏。每节列已有证据、缺失证据和应放的表图，缺失处用“待补实验”而不是编写数值。
```

## 示例输入

```json
{
  "question": "低照度增强如何兼顾颜色保真与噪声抑制？",
  "method": "亮度与细节双分支，使用颜色一致性损失",
  "results": "演示数据：D1 提高 0.4 dB，D2 下降 0.1 dB；速度未测"
}
```

## 预期输出

论文提纲、主张—实验映射与待补材料。

## 适用与边界

适合在已有结果后组织论文。

不能保证论文可录用；演示数值不应直接用于真实稿件。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
