# 撰写可复现性声明

[分类目录](README.md) · [总目录](../../README.md)

ID：`academic-writing/reproducibility-statement`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `available` | 已公开资源 |
| `missing` | 未公开内容与原因 |
| `protocol` | 可复现实验步骤 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
available：{{available}}
missing：{{missing}}
protocol：{{protocol}}

明确资源名称、位置字段、访问条件和复现范围。未公开内容如实写出，不能以“可复现”掩盖缺失权重或私有数据。给出从环境到评测的步骤概述，以及不具备内部数据时可重复哪些结论。没有 URL 时写资源名与待填写位置，不生成假链接。
```

## 示例输入

```json
{
  "available": "训练与推理代码、环境文件；数据需向提供方申请",
  "missing": "内部验证数据不可公开，权重尚未整理",
  "protocol": "公开数据划分与随机种子在配置文件中"
}
```

## 预期输出

可复现性声明与公开前材料检查表。

## 适用与边界

适合论文附录或项目 README。

输入资源名称须真实；最终位置需补齐并检查。
