# 把实现写成可复现方法

[分类目录](README.md) · [总目录](../../README.md)

ID：`academic-writing/method-specification`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `implementation` | 模块和实现细节 |
| `notation` | 符号偏好 |
| `unknowns` | 尚未确定细节 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
implementation：{{implementation}}
notation：{{notation}}
unknowns：{{unknowns}}

按输入输出、模块、数据流、训练目标描述方法。检查张量形状、符号复用和运算合法性，公式必须与实现描述一致。把未知实现列为作者核查项，不自行选超参。输出伪代码，并标记可能影响梯度或数值范围的处理。
```

## 示例输入

```json
{
  "implementation": "输入 RGB [B,3,H,W]；亮度分支输出 [B,1,H,W]；细节分支输出残差；两者相加后裁剪。",
  "notation": "输入 I，照明 L，残差 R，输出 J",
  "unknowns": "损失权重与裁剪前后顺序需核查"
}
```

## 预期输出

方法段落、符号表、形状表及伪代码。

## 适用与边界

适合已有实现但论文描述不清晰时。

需要对照真实代码验证，模板不能执行实现检查。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
