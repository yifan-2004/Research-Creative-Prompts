# 逐点回复审稿意见

[分类目录](README.md) · [总目录](../../README.md)

ID：`academic-writing/reviewer-response`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `comment` | 审稿意见 |
| `changes` | 已经完成的修改 |
| `locations` | 修改位置 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
comment：{{comment}}
changes：{{changes}}
locations：{{locations}}

先准确承认意见所指的问题，再说明实际修改和结果，最后给出可定位位置。只写已完成事项，保留不利结果；未完成项解释范围与原因，不承诺不存在的实验。语气尊重且直接，避免用泛泛感谢掩盖没有回应。
```

## 示例输入

```json
{
  "comment": "缺少户外数据实验，泛化结论依据不足。",
  "changes": "已加入户外集 D2，性能下降 0.1 dB；收窄结论并增加局限。",
  "locations": "第 5.3 节，表 4，第 8 页"
}
```

## 预期输出

可用于 rebuttal 的逐点回复与事实核查项。

## 适用与边界

适合基于实际修订撰写答复。

不能替作者声称已修改，位置需在最终稿核对。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
