# 在字数限制内安排 rebuttal

[分类目录](README.md) · [总目录](../../README.md)

ID：`academic-writing/rebuttal-budget`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `comments` | 意见与重要性 |
| `evidence` | 已有答复证据 |
| `budget` | 总字数限制 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
comments：{{comments}}
evidence：{{evidence}}
budget：{{budget}}

按影响结论的程度排序，给每项分配字数。优先呈现新证据和具体修订，对重复意见合并但保留编号映射。生成完整回复后核对每个意见是否有回应；标记无法在现有材料下答复的项，不虚构补实验。
```

## 示例输入

```json
{
  "comments": "R1：公平比较不足；R2：符号不清；R3：缺少数据来源。",
  "evidence": "补充统一评测，保留表号；已增加数据来源。",
  "budget": "英文 600 词"
}
```

## 预期输出

字数分配表、压缩回复与意见覆盖清单。

## 适用与边界

适合有严格 rebuttal 限额的投稿。

实际词数及会议规则需作者核实。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
