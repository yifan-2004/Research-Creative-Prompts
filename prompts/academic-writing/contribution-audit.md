# 把贡献写成可验证的陈述

[分类目录](README.md) · [总目录](../../README.md)

ID：`academic-writing/contribution-audit`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `draft` | 原贡献列表 |
| `evidence` | 实际支持 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
draft：{{draft}}
evidence：{{evidence}}

逐项辨认方法贡献、实证贡献与资源承诺。删除或收窄超出证据的“首次”“全面”“解决所有”；为每条保留的贡献绑定实验或实现证据。未开源资源用计划措辞且说明发布条件。输出 3 条准确贡献及需补证的原主张。
```

## 示例输入

```json
{
  "draft": "首次解决所有低照度颜色问题；性能全面领先；代码将开源。",
  "evidence": "提出一个颜色约束；D1 领先 0.2 dB，D2 持平；代码尚未公开。"
}
```

## 预期输出

修订贡献列表与证据对应关系。

## 适用与边界

适合投稿前检查创新点表达。

不能凭本列表确认创新性或资源许可。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
