# 把失败案例写成有依据的分析

[分类目录](README.md) · [总目录](../../README.md)

ID：`academic-writing/failure-analysis`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `cases` | 观察及对应编号 |
| `hypotheses` | 可能解释 |
| `evidence` | 已有验证 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
cases：{{cases}}
hypotheses：{{hypotheses}}
evidence：{{evidence}}

按可观察现象、影响、可能机制和待验证实验组织。对未验证原因使用假设措辞，提出能区分竞争解释的对照，不能把视觉印象写成定量结果。建议如何选展示图以避免只挑最差或最好案例，并写一段可放进论文的分析。
```

## 示例输入

```json
{
  "cases": "C1：暖色路灯偏绿；C2：极暗区域噪声被放大；均有原图和输出。",
  "hypotheses": "颜色损失可能过强；训练中极暗样本不足。",
  "evidence": "尚未做针对性消融"
}
```

## 预期输出

失败类型表、验证计划和克制的讨论段落。

## 适用与边界

适合补充质性分析与讨论。

需要真实图像支撑，原因不能从图像单独确认。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
