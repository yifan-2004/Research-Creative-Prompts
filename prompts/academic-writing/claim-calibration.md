# 给学术措辞降到证据支持强度

[分类目录](README.md) · [总目录](../../README.md)

ID：`academic-writing/claim-calibration`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `text` | 待审段落 |
| `evidence` | 实验范围 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
text：{{text}}
evidence：{{evidence}}

标出因果、统计、新颖性和泛化四类过强词。逐句说明需要什么证据才能保留原词，再给证据支持的改写。保留数值、条件和不确定性，不把“不显著”误写成“没有效果”。最后输出可直接替换的段落。
```

## 示例输入

```json
{
  "text": "我们证明该机制显著提高所有场景下的鲁棒性。",
  "evidence": "两个数据集各单次实验，平均 AP 提升 0.4；未做显著性检验。"
}
```

## 预期输出

逐句强度审查、所需证据与修订稿。

## 适用与边界

适合论文结论、摘要和宣传文案核查。

需要领域知识复核，不自动执行统计检验。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
