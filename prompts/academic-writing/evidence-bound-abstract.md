# 写不越过证据的摘要

[分类目录](README.md) · [总目录](../../README.md)

ID：`academic-writing/evidence-bound-abstract`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `facts` | 问题方法和结果 |
| `venue_style` | 长度与语言 |
| `scope` | 适用范围 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
facts：{{facts}}
venue_style：{{venue_style}}
scope：{{scope}}

按问题、方法、实验与限制写摘要。只能使用给定事实，数值保留单位和数据条件，不写“最先进”“显著”除非有对应证据。方法未提供细节时采用概括表达。摘要后列出每个结果句对应的事实，以及需要作者核对的术语。
```

## 示例输入

```json
{
  "facts": "夜景颜色偏差；提出颜色约束；演示测试 PSNR 23.4→23.8，运行时间未知。",
  "venue_style": "英文，150—180 词",
  "scope": "仅配对图像数据 D"
}
```

## 预期输出

一版满足长度约束的摘要及事实核对表。

## 适用与边界

适合摘要起草与压缩。

事实输入必须真实；不能补造实验或引用。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
