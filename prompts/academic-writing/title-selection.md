# 生成准确的论文标题

[分类目录](README.md) · [总目录](../../README.md)

ID：`academic-writing/title-selection`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `core` | 任务与核心机制 |
| `claims` | 已支持的贡献 |
| `style` | 语言与长度 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
core：{{core}}
claims：{{claims}}
style：{{style}}

生成 8 个标题，分别侧重任务、方法与问题。检查每个标题是否暗示未经验证的性能、新颖性或适用范围，逐条说明取舍。不得凭标题虚构模块名称；推荐一个最易被目标领域读者理解的版本。
```

## 示例输入

```json
{
  "core": "低照度图像增强；显式颜色一致性约束",
  "claims": "改善指定配对数据中的颜色误差；不保证所有夜景泛化",
  "style": "英文，不超过 14 个词，不使用新缩写"
}
```

## 预期输出

8 个标题、简短评价和推荐理由。

## 适用与边界

适合论文与技术报告命名。

标题不能替代贡献论证；新颖性须另查。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
