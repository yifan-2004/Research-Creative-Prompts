## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `setup` | 数据训练评测设置 |
| `table` | 结果表 |
| `unknowns` | 缺失信息 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
setup：{{setup}}
table：{{table}}
unknowns：{{unknowns}}

生成实验设置、主结果和消融分析三个部分。把统计可靠性限制写清：单次结果不能据此声称稳定显著。只解释表中可支持的趋势，缺失信息集中列出。保留数据划分、指标定义与比较条件，避免只报最好结果。
```

## 示例输入

```json
{
  "setup": "D 官方划分；相同训练预算；PSNR 在 RGB 原尺寸计算；仅一个随机种子。",

```
