# 把技术笔记写成可复现博客

[分类目录](README.md) · [总目录](../../README.md)

ID：`learning-communication/technical-blog`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `topic` | 主题 |
| `notes` | 真实笔记 |
| `audience` | 读者 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
topic：{{topic}}
notes：{{notes}}
audience：{{audience}}

按现象、最小例子、根因、修复和验证组织文章。代码与截图只引用已提供材料，缺少时列出需要补的内容，不伪造运行效果。解释坐标假设和适用边界，给读者一个能自检的练习。
```

## 示例输入

```json
{
  "topic": "单目 3D 框投影为何错位",
  "notes": "发现 resize 后未缩放 cx、cy；修正后合成框投影对齐",
  "audience": "有 Python 基础的视觉初学者"
}
```

## 预期输出

博客提纲与基于材料的正文草稿。

## 适用与边界

适合公开分享排错经验。

正式发布需运行例子并核对图片来源。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
