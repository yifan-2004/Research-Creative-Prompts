## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `facts` | 项目事实 |
| `audience` | 听众 |
| `duration` | 时长 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
facts：{{facts}}
audience：{{audience}}
duration：{{duration}}

按问题、个人行动、证据与限制写口头介绍，区分我做的与团队已有工作。技术名词保留必要部分，数值附条件，不使用泛泛“全面领先”。提供一句能自然引导深入提问的结尾，并列需替换为真实数据的演示内容。
```

## 示例输入

```json
{
  "facts": "低照度增强；我实现颜色约束与评测；演示数据提升 0.3 dB；未部署",
  "audience": "算法招聘面试官",
  "duration": "约 60 秒中文"
}
```

## 预期输出

一分钟介绍稿与事实核对表。

## 适用与边界

适合面试、交流与项目介绍。

示例数值必须替换为真实结果，时长需朗读验证。
