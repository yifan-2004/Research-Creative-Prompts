## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `progress` | 本周真实进展 |
| `decision` | 希望讨论 |
| `time` | 汇报时长 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
progress：{{progress}}
decision：{{decision}}
time：{{time}}

围绕一个需要讨论的决定安排页面，分别呈现问题、实际工作、证据、失败、选项和请求。每页写一句中心结论及支撑图表，未完成实验清楚标记。给每页时长和可能追问，不用计划填满成果页。
```

## 示例输入

```json
{
  "progress": "完成颜色损失消融；两次种子结果波动较大；第三次运行失败",

  "time": "8 分钟，最多 6 页"
}
```
