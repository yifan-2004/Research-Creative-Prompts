# 把时间预算变成学习产物

[分类目录](README.md) · [总目录](../../README.md)

状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `goal` | 学习目标 |
| `background` | 基础 |
| `budget` | 预算 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
goal：{{goal}}
background：{{background}}
budget：{{budget}}

按依赖拆成小单元，安排阅读、推导、实现和复盘时间。每周必须有可验收产物与自测题，保留缓冲而非排满。给出进度落后时的范围收缩，避免用“掌握全部”作为验收。
```

## 示例输入

```json
{
  "goal": "理解 Transformer 并实现一个小型图像分类模型",
  "background": "会 Python 与基础反向传播",
  "budget": "每周 6 小时，四周"
}
```

## 预期输出

四周计划、每周产物和调整规则。

## 适用与边界

适合自学技术主题。

实际速度因人而异，应按自测结果修订。
