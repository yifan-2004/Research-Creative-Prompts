# 起草明确的学术邮件

[分类目录](README.md) · [总目录](../../README.md)

ID：`learning-communication/professional-email`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `recipient` | 收件对象与称呼 |
| `purpose` | 目的 |
| `facts` | 事实与可用时间 |
| `language` | 语言 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
recipient：{{recipient}}
purpose：{{purpose}}
facts：{{facts}}
language：{{language}}

写主题与正文，开头说明身份背景所需的已知信息，再表达具体请求和可用时间。不要编造附件、既往关系或已经约好的会议；邮箱缺失时只起草不发送。结尾简洁，给出发送前需补的身份或时区信息。
```

## 示例输入

```json
{
  "recipient": "Professor Chen；邮箱尚未提供",
  "purpose": "请求下周讨论低照度增强的实验设计",
  "facts": "已有初步消融；周二 14:00—16:00 或周四 10:00—12:00 可用",
  "language": "英文，礼貌简洁"
}
```

## 预期输出

主题、邮件正文与发送前待补项。

## 适用与边界

适合约讨论与学术沟通。

只生成草稿，不授权发送；时间与时区需核对。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
