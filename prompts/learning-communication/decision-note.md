# 把技术讨论整理成决定记录

[分类目录](README.md) · [总目录](../../README.md)

ID：`learning-communication/decision-note`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `discussion` | 讨论记录 |
| `context` | 背景 |
| `owners` | 责任信息 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
discussion：{{discussion}}
context：{{context}}
owners：{{owners}}

提取背景、备选、最终决定、理由、责任人与复查时间。未达成的内容写待定，不替团队补决定；将验证阈值缺失标为行动项。保留反对意见的事实依据，输出能被后来者理解的短记录。
```

## 示例输入

```json
{
  "discussion": "A 想全量微调；B 担心小数据过拟合；决定先线性探测，周五看验证结果",
  "context": "2,000 张夜景图，算力三天",
  "owners": "实验由 Yifan 执行，阈值尚未定"
}
```

## 预期输出

决定记录、未决项与复查条件。

## 适用与边界

适合组会或技术评审后。

只能依据讨论记录，需参与者确认准确性。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
