# 把周复盘变成下周行动

[分类目录](README.md) · [总目录](../../README.md)

ID：`learning-communication/weekly-reflection`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `log` | 本周记录 |
| `goal` | 阶段目标 |
| `time` | 下周可用时间 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
log：{{log}}
goal：{{goal}}
time：{{time}}

区分事实、原因假设和情绪评价，找出真正阻塞目标的环节。提出最多三项可执行调整，每项有时间预算、产物和停止条件。保留缓冲，不用“更努力”代替流程变化，也不根据一次失误评价能力。
```

## 示例输入

```json
{
  "log": "计划 4 次训练，完成 2 次；一次环境故障；一篇论文读到方法部分",
  "goal": "两周后确认颜色损失是否有效",
  "time": "18 小时"
}
```

## 预期输出

简短复盘与三项下周行动。

## 适用与边界

适合研究或自学进度管理。

原因需要持续观察，单周日志不代表长期规律。
