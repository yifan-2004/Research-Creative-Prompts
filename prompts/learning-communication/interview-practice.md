## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `project` | 真实经历 |
| `role` | 目标岗位 |
| `limits` | 不能夸大的内容 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
project：{{project}}
role：{{role}}
limits：{{limits}}

生成从任务、方法、实验、失败到个人贡献的逐级追问题。示范回答只能依据真实经历，不把团队工作或未做的事情写成个人成果。先问一道问题，给优秀回答的结构和需准备的真实证据，后续按回答反馈。
```

## 示例输入

```json
{
  "project": "实现低照度增强模型，负责数据处理和颜色损失消融",
  "role": "计算机视觉算法实习",
  "limits": "没有线上部署，没有多机训练经验"
}
```

## 预期输出

首轮问题、评价标准与证据准备表。

## 适用与边界

适合项目面试练习。

模板不能替代实际经验，不应编造经历。
