# 逐步提示而非直接代答

[分类目录](README.md) · [总目录](../../README.md)

ID：`learning-communication/socratic-tutor`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `problem` | 题目 |
| `attempt` | 已有思路 |
| `style` | 辅导方式 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
problem：{{problem}}
attempt：{{attempt}}
style：{{style}}

从我的已有思路出发，先提出一个能推动下一步的具体问题。不要一次输出完整答案；根据回答再补提示，遇到误区用小例子纠正。当前只给第一个问题与需要观察的量，保持术语一致。
```

## 示例输入

```json
{
  "problem": "为什么图像 resize 后需要修改相机内参？",
  "attempt": "像素坐标变了，但不知道焦距怎么变",
  "style": "一次只给一个提示，等我回答"
}
```

## 预期输出

一个针对性提示及后续互动方向。

## 适用与边界

适合交互式学习。

需要多轮对话，单轮不会完成整套辅导。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
