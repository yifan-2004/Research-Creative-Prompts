# 把材料变成可检索记忆卡

[分类目录](README.md) · [总目录](../../README.md)

ID：`learning-communication/active-recall-cards`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `notes` | 学习材料 |
| `level` | 难度 |
| `format` | 格式 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
notes：{{notes}}
level：{{level}}
format：{{format}}

生成覆盖定义、区别、应用和反例的独立问题，答案短且可判断对错。每张卡只测一个核心点，答案依据材料；缺少内容不补成事实。标记易混淆项，并安排间隔复习建议，不声称已经优化记忆效果。
```

## 示例输入

```json
{
  "notes": "训练集拟合参数；验证集选超参；测试集只用于最终评估。",
  "level": "初学者",
  "format": "问答卡，含一个反例题"
}
```

## 预期输出

8 张问答卡与复习安排建议。

## 适用与边界

适合读后自测。

材料过少时卡片可能重复，应人工筛选。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
