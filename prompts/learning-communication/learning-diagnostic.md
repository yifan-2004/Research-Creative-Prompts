# 先诊断知识缺口再安排学习

[分类目录](README.md) · [总目录](../../README.md)

ID：`learning-communication/learning-diagnostic`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `topic` | 主题 |
| `background` | 基础 |
| `goal` | 目标 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
topic：{{topic}}
background：{{background}}
goal：{{goal}}

先给 6 个逐级诊断题，覆盖必要概念而非冷僻记忆。根据用户答案再调整路径；本轮先提供题目和判分标准，不假定已经答错。区分概念、推导和实现能力，提出最小补课单元。
```

## 示例输入

```json
{
  "topic": "单目 3D 检测",
  "background": "熟悉 CNN 和 PyTorch，不熟相机坐标与投影",
  "goal": "四周后能读懂模型中的深度与 3D 框回归"
}
```

## 预期输出

诊断题、评分依据与条件式学习路径。

## 适用与边界

适合开始新方向前。

没有实际回答不能判断个人水平。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
