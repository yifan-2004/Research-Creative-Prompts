# 用复述暴露理解断点

[分类目录](README.md) · [总目录](../../README.md)

ID：`learning-communication/teach-back`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `concept` | 概念 |
| `my_explanation` | 我的复述 |
| `level` | 目标层次 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
concept：{{concept}}
my_explanation：{{my_explanation}}
level：{{level}}

先准确复述我说的意思，再指出具体混淆与正确对应。用一个最小例子解释，不只说“错了”。给出两个反例和三个追问，让我重新解释；不要因为一段错误复述推断整体能力。
```

## 示例输入

```json
{
  "concept": "相机内参与外参的区别",
  "my_explanation": "内参描述相机相对世界的位置，外参描述焦距。",
  "level": "初学者，能看懂投影公式"
}
```

## 预期输出

针对性纠错、例子与复述练习。

## 适用与边界

适合学习后自检。

需要用户继续回答才能确认理解改善。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
