## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
formula：{{formula}}
known：{{known}}
goal：{{goal}}

定义每个符号与单位，逐步代入计算，检查量纲和坐标假设。再只改变一个变量生成对比例子，解释趋势和公式失效边界。最后给一道未解练习及答案放在独立区域，避免跳过中间步骤。
```

## 示例输入

```json
{
  "formula": "u = fx * X / Z + cx",
  "known": "fx=800，cx=320，X=1m，Z=10m",
  "goal": "理解深度变化如何影响像素位置"
}
```

## 预期输出

逐步解题、单变量对比与练习。

## 适用与边界

适合公式理解与基础推导。

假设需与实际坐标系一致，公式不覆盖镜头畸变。
