## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
methods：{{methods}}
data：{{data}}
focus：{{focus}}

分别设计配对与无配对协议；配对集可报告全参考指标，无配对集不能捏造 PSNR。按曝光、噪声和场景分层，统一显示范围与裁剪区域，保留失败案例。下游检测需固定检测器或明确联合训练，避免把检测器变化归因于增强。
```

## 示例输入

```json
{
  "methods": "我的增强模型、恒等映射、gamma 基线",
```

无配对无参考指标不能单独证明视觉质量优越。
