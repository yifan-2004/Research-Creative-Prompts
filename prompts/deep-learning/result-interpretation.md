## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `results` | 真实结果摘要 |
| `protocol` | 协议 |
| `decision` | 需要的决定 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
results：{{results}}
protocol：{{protocol}}
decision：{{decision}}

先核对指标方向与可比性，再分别解释像素误差、感知相似和人工观察。按应用目标讨论取舍，提出盲评或分层分析来验证视觉结论。保留所有指标，不能用综合分数隐藏冲突；若需要加权，明确权重由使用目标决定。
```

## 示例输入

```json
{
  "results": "演示：A 的 PSNR 更高，B 的 LPIPS 更低；B 在极暗图上有颜色漂移",
  "protocol": "同一测试划分、同一预处理；仅一个种子",
  "decision": "选哪个模型进入演示"
}
```

## 预期输出

指标解读、应用取舍与补充验证计划。

不能依据数字推断具体视觉效果；演示结果并非实测。
