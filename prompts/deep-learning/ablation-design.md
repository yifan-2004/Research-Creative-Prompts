## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `modules` | 新增组件 |
| `hypothesis` | 各组件预期作用 |
| `budget` | 可训练次数 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
modules：{{modules}}
hypothesis：{{hypothesis}}
budget：{{budget}}

设计能分离主效应与关键交互的实验矩阵。保持训练配方一致，指出移除组件后参数量或计算量变化可能造成的混杂，并安排预算匹配对照。为每个假设绑定主要指标和失败案例，不事后仅选择有利指标。给出优先执行顺序。
```

## 示例输入

```json
{
  "modules": "颜色损失 C、频域模块 F、亮度分支 L",
  "hypothesis": "C 控制偏色，F 保持纹理，L 提升亮度",
  "budget": "最多 8 次，含完整模型"
}
```

## 预期输出

消融矩阵、混杂说明与预期判别关系。

## 适用与边界

适合多模块研究设计。

八次预算可能无法估计全部交互与随机波动。
