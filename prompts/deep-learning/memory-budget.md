## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `model` | 模型训练设置 |
| `failure` | 故障 |
| `constraints` | 不能改变的条件 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
model：{{model}}
failure：{{failure}}
constraints：{{constraints}}

将显存拆分为参数、梯度、优化器状态、激活与临时工作区。提出先测量再调整的顺序，分别讨论裁剪、累积、检查点和算子实现对速度与训练语义的影响。给出测峰值、清空旧引用与最小 batch 复测的方法；不要把累积当成所有层都等价的大 batch。
```

## 示例输入

```json
{
  "model": "Transformer，batch 4，1024×1024，AdamW，混合精度",

```
