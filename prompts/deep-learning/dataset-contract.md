## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `task` | 任务 |
| `sample` | 样本结构 |
| `pipeline` | 预处理流程 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
task：{{task}}
sample：{{sample}}
pipeline：{{pipeline}}

定义样本字段、形状、取值范围、配对键和异常处理策略。列出必须在训练前检查的条件：数量、重复、损坏、色彩空间、配对对齐和变换同步。为每个检查给出失败示例与处理决定，不能默认除以 255 适用于所有位深。输出数据加载器应遵守的接口契约。
```

## 示例输入

```json
{
  "task": "配对低照度图像增强",
  "sample": "low/0001.png 与 high/0001.png，RGB，尺寸一致",
  "pipeline": "读取后转 float32，除以 255，随机裁剪 256×256"
}
```

数据契约表、预检清单、异常样本处理规则。
