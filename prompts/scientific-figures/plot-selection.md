## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `data` | 数据结构 |
| `question` | 读者需要判断 |
| `context` | 使用场景 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
data：{{data}}
question：{{question}}
context：{{context}}

推荐主要图形与一项备选，解释坐标、单位、标记和筛选线。区分比较、分布与关系；避免不必要 3D 和双轴。提出缺失值、重复测量与误差条的处理方式，只使用实际数据，不推测未测结果。
```

## 示例输入

```json
{
  "data": "12 个模型，每个有 AP、延迟、参数量",
  "question": "在 30ms 延迟以内哪个模型准确率更高？",
  "context": "论文结果页，静态 PDF"
}
```
