## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `variants` | 真实模型变体 |
| `metrics` | 可用结果 |
| `claim` | 待表达主张 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
variants：{{variants}}
metrics：{{metrics}}
claim：{{claim}}

用模块矩阵展示配置，用点图展示结果与运行波动。明确只比较实际训练过的变体，检查互补是否需要交互分析而非看完整模型最高。对参数量变化单独报告，输出能与实验表相互核对的标签规则。
```

## 示例输入

```json
{
  "variants": "基础模型、+C、+F、+C+F",
  "metrics": "每个变体有 PSNR、参数量和三次种子结果",
  "claim": "颜色约束与频域模块是否互补"
}
```
