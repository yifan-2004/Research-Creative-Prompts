## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `structure` | 已确认网络结构 |
| `details` | 需要标注 |
| `style` | 版式 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
structure：{{structure}}
details：{{details}}
style：{{style}}

先输出节点、边和张量形状表，核查分支合并是否合法，再给可用于 SVG 或绘图工具的布局规格。未知内部块用整体模块表示，禁止为了美观添加不存在的注意力或损失。区分训练专用与推理路径，附结构忠实性核对单。
```

## 示例输入

```json
{
  "structure": "RGB→编码器→亮度分支与细节分支→融合→增强图；亮度分支输出单通道",
  "details": "输入输出形状、跳跃连接；内部块未提供",
  "style": "双栏论文通栏，矢量图，色盲友好"
}
```

## 预期输出

结构表、图形规格、标签和核查单。

## 适用与边界

适合论文网络图重绘。

必须与代码或作者确认结构，不可用生成式图片改变方法事实。
