| 变量 | 填写说明 |
| --- | --- |
| `inputs` | 现有材料 |
| `geometry` | 约定 |
| `layout` | 展示需要 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
inputs：{{inputs}}
geometry：{{geometry}}
layout：{{layout}}

列出从框中心、尺寸和偏航角生成角点再投影的步骤，明确坐标轴、尺寸顺序和图像缩放后的内参。规定阈值、类别颜色、遮挡和无效深度处理；鸟瞰图标单位与相机位置。建议用已知合成框先验证几何，不把示例框当实测预测。
```

## 示例输入

```json
{
  "inputs": "RGB 图、相机内参、相机坐标 3D 框、置信度",
  "geometry": "x 右、y 下、z 前；尺寸为长宽高",
  "layout": "图像投影框与鸟瞰图并排"
}
```
