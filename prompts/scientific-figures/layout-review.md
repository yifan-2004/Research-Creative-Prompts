## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `figure` | 图或已观察问题 |
| `target` | 目标尺寸 |
| `requirements` | 必须保留 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
figure：{{figure}}
target：{{target}}
requirements：{{requirements}}

按文字、层级、线条、配色、留白与图例逐项审阅。未附图时只依据描述给建议，不能声称看见图。优先删冗余装饰、增加层次、拆分面板，保留科学信息；输出按影响排序的具体修改和最终尺寸检查方法。
```

## 示例输入

```json
{
  "figure": "单栏网络图，标签约 5pt，三种箭头未解释",
  "target": "最终 85mm 宽 PDF",
  "requirements": "模块名、张量形状与训练专用支路"
}
```
