## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `training` | 训练流程 |
| `inference` | 推理流程 |
| `special_inputs` | 额外监督 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
training：{{training}}
inference：{{inference}}
special_inputs：{{special_inputs}}

用不同边型区分数据、监督与参数更新；训练专用传感器或伪标签需显式标注。分成训练与推理两个面板，共享模块使用同名。给出节点边清单和简明图注，不能因为推理纯视觉而删去训练额外监督。
```

## 示例输入

```json
{
  "training": "RGB 与标签→网络→预测→损失→梯度更新",
  "inference": "仅 RGB→网络→预测框→可视化",
  "special_inputs": "训练时使用由点云生成的深度标签"
}
```
