# 把宽结果表转成可读图

[分类目录](README.md) · [总目录](../../README.md)

ID：`scientific-figures/table-to-figure`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `table` | 表结构 |
| `question` | 主要信息 |
| `layout` | 展示限制 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
table：{{table}}
question：{{question}}
layout：{{layout}}

先说明“稳定”应如何定义，不能直接把不同难度数据集原始分数相加。比较按数据集相对基线变化、排名或小倍图的利弊；缺失值保留空白，不能补零。推荐一个主图并保留完整表，提供标签、单位和图例规格。
```

## 示例输入

```json
{
  "table": "8 方法×6 数据集的 PSNR；缺失单元为未报告",
  "question": "哪个方法跨数据集更稳定？",
  "layout": "单栏宽，允许补充材料放完整表"
}
```

## 预期输出

变换建议、主图方案与缺失值规则。

## 适用与边界

适合多数据集大表压缩。

排名会丢失幅度信息，归一化方式需明确。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
