# 写可独立理解的图注

[分类目录](README.md) · [总目录](../../README.md)

ID：`scientific-figures/figure-caption`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `figure` | 图中内容 |
| `protocol` | 展示协议 |
| `finding` | 可支持的观察 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
figure：{{figure}}
protocol：{{protocol}}
finding：{{finding}}

写清任务、行列含义、颜色符号、显示处理与关键观察。将视觉观察限定到图中样本，不扩展成总体性能结论。数值、误差条和缩写都需解释；未提供的统计不补写。给出短版与详细版图注。
```

## 示例输入

```json
{
  "figure": "三组夜景的输入、基线、本文结果；红框为放大区",
  "protocol": "所有图同一线性显示范围，放大 4 倍",
  "finding": "第二组本文保留更多可见纹理；无人工评分"
}
```

## 预期输出

两版图注与缺失信息列表。

## 适用与边界

适合论文图注编辑。

图注不能证明未统计的趋势。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
