## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
paper：{{paper}}
audience：{{audience}}
layout：{{layout}}

把三段分别定义为输入现象、实际机制和真实证据。提出构图与标签，结果面板只能使用已有输出或表格，不生成假的前后对比。概念示意与真实结果用明确标签区分；只保留一个可支持的中心结论。
```

## 示例输入

```json
{
  "paper": "一种低照度增强方法，使用颜色约束；在指定数据集改善颜色误差",
  "audience": "计算机视觉读者",
  "layout": "横向三段：问题、方法、证据，少文字"
}
```

三段布局、标签文案与材料清单。
