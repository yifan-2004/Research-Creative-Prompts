## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `series` | 系列数量与含义 |
| `medium` | 载体 |
| `constraints` | 视觉约束 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
series：{{series}}
medium：{{medium}}
constraints：{{constraints}}

给出具体十六进制颜色、线型和点形组合，保证语义与图例顺序一致。建议用色盲模拟和灰度检查验证，而不是声称凭色码即可保证无障碍。避免将高饱和强调色分配给所有系列，提供打印备选。
```

## 示例输入

```json
{
  "series": "五个方法，其中一个是本文模型",
  "medium": "白底论文 PDF，可能黑白打印",
  "constraints": "不只靠红绿区分，本文模型可强调"
}
```

## 预期输出

颜色—线型—点形映射表与检查流程。

## 适用与边界

适合折线图、散点图与多方法比较。

实际可辨性取决于尺寸和显示设备，需渲染检查。
