| 变量 | 填写说明 |
| --- | --- |
| `observations` | 数据 |
| `meaning` | 重复单位 |
| `goal` | 比较目标 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
observations：{{observations}}
meaning：{{meaning}}
goal：{{goal}}

说明样本数、重复单位与误差条定义，比较 SD、SE 与置信区间回答的问题。小样本优先显示每次运行点，选择合适汇总并写清假设；不从误差条是否重叠直接得出显著性。给出图注与统计复核建议。
```

## 示例输入

```json
{
  "observations": "演示：模型 A 的三次 AP 为 39.1、39.5、39.2；B 为 39.3、39.4、39.7",
  "meaning": "独立训练种子，不是同一模型重复推理",
  "goal": "展示均值和训练波动"
}
```

图形方案、误差条定义、图注和统计注意点。
