# 分析文献结论冲突

[分类目录](README.md) · [总目录](../../README.md)

ID：`research-literature/contradictory-evidence`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `findings` | 冲突结果及条件 |
| `question` | 需要解决的判断 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
findings：{{findings}}
question：{{question}}

先检查任务、数据、指标、训练方式和域差异是否一致。提出可能解释冲突的因素，每个因素写出可区分解释的最小实验和预期观测。不要为了统一叙事忽略反证；给出按条件成立的结论与当前无法下结论的部分。
```

## 示例输入

```json
{
  "findings": "[S1] 增强提高白天检测 AP；[S2] 增强降低夜间小目标 AP。",
  "question": "增强是否应固定放在检测器之前？"
}
```

## 预期输出

冲突条件表、竞争解释、判别实验与条件式结论。

## 适用与边界

适合面对不同论文得出不同结果的情况。

竞争解释是假设，需实验验证。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
