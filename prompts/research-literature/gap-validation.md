# 验证研究空白而非编造空白

[分类目录](README.md) · [总目录](../../README.md)

ID：`research-literature/gap-validation`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `candidate_gap` | 候选空白 |
| `evidence` | 已有检索证据 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
candidate_gap：{{candidate_gap}}
evidence：{{evidence}}

先把“未见证据”和“证明不存在”分开。列出会推翻候选空白的反例类型，设计补充检索与前后向引用追踪。把原主张改写为可被现有证据支持的弱表述，并提出与已有工作的差异可用什么实验验证。不得用“首次”“从未”填补检索不足。
```

## 示例输入

```json
{
  "candidate_gap": "现有低照度增强很少显式评估下游检测稳定性",
  "evidence": "已读 8 篇，其中 2 篇报告检测指标；检索范围尚不完整。"
}
```

## 预期输出

反例搜索计划、证据边界、修订后的研究动机。

## 适用与边界

适合写选题依据与创新点前。

研究空白依赖检索覆盖；该模板不认证新颖性。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
