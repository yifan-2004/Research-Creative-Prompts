# 从文献摘录建立证据矩阵

[分类目录](README.md) · [总目录](../../README.md)

ID：`research-literature/evidence-matrix`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `sources` | 带来源标识的摘录 |
| `question` | 调研主题 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
sources：{{sources}}
question：{{question}}

逐条抽取任务、方法、数据集、评价协议、数值、对照和限制，并在每个事实后保留来源标识。缺失项写“未提供”。只比较相同数据划分与协议下的结果，把无法直接比较的项隔开。最后区分直接证据、作者解释和你的推断，提出需要回看原文的疑点。
```

## 示例输入

```json
{
  "sources": "[S1, p.4] 在 LOL-v1 测试集报告 PSNR 24.1；[S2, Table 2] 在自建夜景集报告 SSIM 0.82。",
  "question": "低照度增强方法的效果与泛化证据"
}
```

## 预期输出

来源可追溯的证据表、可比性分组、待核查清单。

## 适用与边界

适合已有论文摘录后的结构化整理。

不能据不完整摘录断言某方法最好；输入中的示例数值仅为演示数据。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
