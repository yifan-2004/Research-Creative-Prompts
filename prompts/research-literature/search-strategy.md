# 设计可复现的文献检索式

[分类目录](README.md) · [总目录](../../README.md)

ID：`research-literature/search-strategy`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `question` | 待检索问题 |
| `platforms` | 检索平台 |
| `scope` | 时间语言范围 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
question：{{question}}
platforms：{{platforms}}
scope：{{scope}}

拆分研究问题的概念块，给出同义词、排除词和 3 级检索式：宽召回、主题聚焦、补充检索。按平台说明哪些语法需在实际界面确认，不能把一个平台的高级语法默认套给另一个。提供检索日期、原始式、命中数、去重规则的记录表。没有联网结果时只设计方案，不列出假装检索到的论文。
```

## 示例输入

```json
{
  "question": "低照度增强中噪声与颜色偏差如何联合处理？",
  "platforms": "Google Scholar、IEEE Xplore、arXiv",
  "scope": "2020—2026 年，英文为主，也收录经典方法"
}
```

## 预期输出

概念词表、平台对应检索式、可填写检索日志。

## 适用与边界

适合开始系统调研前建立检索路径。

检索式需在平台试跑；不能保证完整覆盖或实时语法有效。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
