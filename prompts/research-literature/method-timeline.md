## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `records` | 带时间与来源的论文卡片 |
| `axis` | 分析轴 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
records：{{records}}
axis：{{axis}}

按记录时间建立时间线，同时按解决的问题分支组织。区分“先后出现”“明确继承”“看起来相关”，只在来源提供引用关系时画继承箭头。提取每一阶段缓解了什么瓶颈、留下什么代价；时间相同或版本变更保留备注。
```

## 示例输入

```json
{
  "records": "[P1, 2021] 使用几何深度约束；[P2, 2023] 使用不确定性加权；两者引用关系未知。",
  "axis": "深度估计与误差建模"
}
```

## 预期输出

带来源的方法时间线、问题分支图文本、未确认关系。

## 适用与边界

适合综述背景与组会汇报。

时间先后不证明影响关系；缺失论文可能改变脉络。
