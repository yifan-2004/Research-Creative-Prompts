## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
draft：{{draft}}
sources：{{sources}}

将段落拆成最小事实主张，分别判断支持、部分支持、不支持或无法核验。写出准确的来源定位和缺失证据，特别核查“显著”“证明”“普适”等强措辞。输出保留原意但与证据强度一致的修订段落，不增加新引用。
```

## 示例输入

```json
{
  "draft": "方法 A 显著提升户外性能，并证明颜色一致性是关键。",
  "sources": "[S1, Table 1] 室内测试 PSNR 提升 0.3 dB；未给显著性检验。"
}
```
