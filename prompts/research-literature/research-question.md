# 把兴趣收敛成可研究问题

[分类目录](README.md) · [总目录](../../README.md)

ID：`research-literature/research-question`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `topic` | 研究兴趣 |
| `constraints` | 资源与时间 |
| `known_evidence` | 已有证据 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
topic：{{topic}}
constraints：{{constraints}}
known_evidence：{{known_evidence}}

先区分已知事实、我的初步观察和待验证假设。提出 3 个能被实验否证的研究问题，每个问题写清自变量、因变量、对照组、失败标准和最低可行实验。依据资源约束排序，说明所需数据及无法从现有证据推出的结论。不要编造相关论文或新颖性证明；给出应检索的方向。
```

## 示例输入

```json
{
  "topic": "真实相机低照度图像增强",
  "constraints": "单张 24GB GPU，8 周，可使用公开配对数据",
  "known_evidence": "初步观察：模型在亮度提升时可能放大噪声，尚未做统计。"
}
```

## 预期输出

3 行研究问题对比表，以及推荐问题的两周验证计划。

## 适用与边界

适合课题起步与缩小范围。

只能提出研究假设；新颖性需独立检索，观测相关性不等于因果。
