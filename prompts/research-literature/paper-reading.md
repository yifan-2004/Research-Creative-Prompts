## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `paper` | 论文文本或关键章节 |
| `focus` | 阅读目标 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
paper：{{paper}}
focus：{{focus}}

仅依据提供文本总结问题、核心机制、训练目标和实验结论。每个关键判断指向页码或段落；无法定位时标注“原文未提供”。给出方法的输入输出与数据流，指出结论依赖的条件，再列 5 个需要阅读附录或代码才能回答的问题。用一段通俗解释帮助理解，但不要让类比取代算法细节。
```

## 示例输入

```json
{
  "paper": "示例摘录：[p.2] 通过亮度分支估计照明；[p.5] 仅报告室内数据结果。",
  "focus": "判断方法是否适用于户外夜景"
}
```

## 预期输出

一页精读卡：问题、机制、证据、条件、复查问题。

## 适用与边界

适合阅读论文时保留可核对笔记。

输入不完整时不能补写损失公式、实现或作者动机。
