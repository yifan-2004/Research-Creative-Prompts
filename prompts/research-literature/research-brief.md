# 把调研变成导师可决策简报

[分类目录](README.md) · [总目录](../../README.md)

ID：`research-literature/research-brief`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `notes` | 已确认调研笔记 |
| `decision` | 需要导师决策 |
| `constraints` | 约束 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
notes：{{notes}}
decision：{{decision}}
constraints：{{constraints}}

将笔记压缩成问题、已有证据、主要未知、两个备选方案和本次需要的决定。每个方案列成本、可验证收益、主要风险与停止条件。把事实与建议分开，用明确的下一步替代泛泛总结；不要把尚未实施的计划写成成果。
```

## 示例输入

```json
{
  "notes": "读了 6 篇；三篇用室内数据；公开数据可用；尚无户外测试。",
  "decision": "优先扩大数据还是改进网络？",
  "constraints": "四周后提交阶段报告"
}
```

## 预期输出

一页简报和一句明确的决策请求。

## 适用与边界

适合组会前同步研究进展。

建议取决于材料完整性，不应代替导师专业判断。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
