# 评估论文复现可行性

[分类目录](README.md) · [总目录](../../README.md)

ID：`research-literature/reproduction-triage`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `materials` | 现有材料 |
| `resources` | 可用资源 |
| `target` | 复现目标 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
materials：{{materials}}
resources：{{resources}}
target：{{target}}

审查数据访问、依赖、算力、关键超参、随机种子、权重和评测协议。区分硬阻塞与可替代项，给出最小运行、缩小实验、完整复现三个层次的验收标准。明确哪些替代会改变论文结论的可比性，先安排最快验证关键假设的试验。
```

## 示例输入

```json
{
  "materials": "论文正文、公开训练代码；数据可申请，权重未发布。",
  "resources": "单张 24GB GPU，14 天，不能使用付费数据",
  "target": "复现主要趋势而非逐位一致的数值"
}
```

## 预期输出

阻塞清单、资源估算范围、分层复现计划。

## 适用与边界

适合决定投入哪篇论文复现。

资源估算不能代替实际计时；未知项应保留范围。
