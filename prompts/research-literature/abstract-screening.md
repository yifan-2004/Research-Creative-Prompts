# 按标准筛选论文摘要

[分类目录](README.md) · [总目录](../../README.md)

ID：`research-literature/abstract-screening`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `criteria` | 纳入排除标准 |
| `abstracts` | 带编号摘要 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
criteria：{{criteria}}
abstracts：{{abstracts}}

逐篇按每条标准判断满足、不满足或摘要无法确定。引用对应摘要原句的短片段说明理由，不能从标题猜测传感器配置。输出纳入、排除和待全文核查三类，保留排除理由，遇到多义表达优先进入待核查。
```

## 示例输入

```json
{
  "criteria": "纳入：推理仅用单张 RGB；排除：多相机、多帧或点云输入。",
  "abstracts": "[A1] 本方法使用连续两帧估计深度；[A2] 本方法从单张图像预测 3D 框。"
}
```

## 预期输出

逐篇筛选表与需要全文确认的问题。

## 适用与边界

适合批量初筛，供人工复核。

摘要不能确认全部训练和推理设置；不要作为最终自动拒收。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
