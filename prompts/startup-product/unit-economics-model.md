## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `business` | 业务 |
| `inputs` | 已知演示参数 |
| `unknowns` | 未知量 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
business：{{business}}
inputs：{{inputs}}
unknowns：{{unknowns}}

写出收入、变动成本、贡献毛利和获客回收的公式，明确税费及固定成本是否包含。未知参数使用有标签的情景范围，不能伪装成实测。做敏感性分析说明最影响结果的变量，并给采集真实参数的方法。
```

## 示例输入

```json
{
  "business": "每份文献报告按次收费",
  "inputs": "价格 12 元；模型成本 3 元；支付费率 1%；人工支持平均 2 分钟",
  "unknowns": "人工分钟成本、退款率、获客成本"
}
```
