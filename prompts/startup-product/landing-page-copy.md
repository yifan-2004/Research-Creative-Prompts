## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `product` | 产品与用户 |
| `capabilities` | 已实现功能 |
| `proof` | 可公开证据 |
| `cta` | 行动入口 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
product：{{product}}
capabilities：{{capabilities}}
proof：{{proof}}
cta：{{cta}}

写标题、副标题、三个价值点、工作流程、真实演示说明和行动按钮。价值表达必须对应已有功能，不能虚构用户数、节省比例或合作机构。对尚未实现功能明确区分；给出简短隐私说明需要产品方确认的字段。
```

## 示例输入

```json
{
  "product": "面向研究生的论文精读卡工具",

}
```
