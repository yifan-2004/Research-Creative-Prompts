# 把创业点子改成待验证问题

[分类目录](README.md) · [总目录](../../README.md)

ID：`startup-product/problem-discovery`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `idea` | 点子 |
| `audience` | 目标用户 |
| `observations` | 已有观察 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
idea：{{idea}}
audience：{{audience}}
observations：{{observations}}

将产品功能与用户问题分开，列出现有证据、假设和反例。把价值主张拆成频率、成本、当前替代方案和付费动机，设计三项最便宜的验证。不能把两位同学的反馈当市场规模或普遍需求；给出明确停止条件。
```

## 示例输入

```json
{
  "idea": "给研究生做自动论文调研助手",
  "audience": "每周读 10 篇视觉论文的硕博生",
  "observations": "两位同学说整理引用耗时，尚未访谈更多人"
}
```

## 预期输出

问题假设表、反例与低成本验证计划。

## 适用与边界

适合创业方向早期筛选。

不能验证市场需求或预测收入。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
