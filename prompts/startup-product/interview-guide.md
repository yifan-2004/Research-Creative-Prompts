# 写不诱导答案的用户访谈

[分类目录](README.md) · [总目录](../../README.md)

ID：`startup-product/interview-guide`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `audience` | 访谈对象 |
| `hypothesis` | 待验证假设 |
| `duration` | 访谈时长 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
audience：{{audience}}
hypothesis：{{hypothesis}}
duration：{{duration}}

围绕最近一次真实经历询问过程、成本、替代工具和后果，避免“你会不会用我们的产品”等诱导题。安排追问与证据记录，不先推销方案。区分受访者行为、意见和假设付费；给出结束时可请求的材料及知情同意说明。
```

## 示例输入

```json
{
  "audience": "做计算机视觉实验的研究生",
  "hypothesis": "他们难以追溯实验配置和结果",
  "duration": "20 分钟"
}
```

## 预期输出

20 分钟访谈提纲、追问和记录表。

## 适用与边界

适合需求探索。

访谈表态不等于实际购买，需后续行为验证。
