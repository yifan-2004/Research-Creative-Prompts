# 设计价格验证而非猜收入

[分类目录](README.md) · [总目录](../../README.md)

ID：`startup-product/pricing-hypotheses`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `value` | 用户获得的价值 |
| `costs` | 成本信息 |
| `audience` | 用户 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
value：{{value}}
costs：{{costs}}
audience：{{audience}}

提出按量、订阅和团队三种计费假设，解释各自与价值及成本的匹配。列出必须实测的单位成本、支持成本和滥用边界；用访谈、透明预售意向或小范围真实支付验证，不诱导虚假稀缺。不得编造收入预测或推荐保证盈利的价格。
```

## 示例输入

```json
{
  "value": "减少论文整理步骤，导出可编辑笔记",
  "costs": "模型调用随页数增长；单次成本未实测",
  "audience": "个人研究生与小实验室"
}
```

## 预期输出

价格假设表、成本字段与验证设计。

## 适用与边界

适合寻找商业模式。

不构成财务预测，价格需市场和成本数据。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
