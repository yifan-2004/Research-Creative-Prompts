# 制定小范围真实发布计划

[分类目录](README.md) · [总目录](../../README.md)

ID：`startup-product/launch-plan`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `product` | 产品现状 |
| `audience` | 首批人群 |
| `constraints` | 约束 |
| `success` | 目标 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
product：{{product}}
audience：{{audience}}
constraints：{{constraints}}
success：{{success}}

设计发布前验收、招募说明、反馈渠道、错误监控和回退。把使用限制与测试状态写清楚，允许退出与删除数据；只规划消息，未经授权不发送。以学习目标制定一周安排，不捏造下载量或增长预期。
```

## 示例输入

```json
{
  "product": "论文精读工具，核心流程已在本地跑通",
  "audience": "同方向研究小组的 15 位志愿测试者",
  "constraints": "不发垃圾消息，只联系明确同意参与者",
  "success": "找到三类真实失败并完成修复"
}
```

## 预期输出

一周计划、招募文案、验收与回退清单。

## 适用与边界

适合封闭测试和早期发布。

需实际授权与渠道，计划不代表已发布。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
