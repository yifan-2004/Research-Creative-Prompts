# 为小产品选择可行动指标

[分类目录](README.md) · [总目录](../../README.md)

ID：`startup-product/product-metrics`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `product` | 产品 |
| `stage` | 阶段 |
| `goal` | 当前目标 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
product：{{product}}
stage：{{stage}}
goal：{{goal}}

选择一个主要结果指标与少量诊断指标，定义事件、分母、时间窗和去重规则。区分试用点击、报告完成、实际使用与留存，避免小样本虚假精确。提出访谈配合行为数据的验证方式，说明最小必要采集与删除规则。
```

## 示例输入

```json
{
  "product": "实验报告生成器",
  "stage": "20 名封闭测试用户",
  "goal": "确认报告是否被用于真实研究决策"
}
```

## 预期输出

指标字典、事件方案与决策阈值设定方法。

## 适用与边界

适合封闭测试阶段。

不能从小样本可靠估计长期留存或市场规模。

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
