# 从证据建立用户分组

[分类目录](README.md) · [总目录](../../README.md)

ID：`startup-product/persona-evidence`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `notes` | 访谈摘要 |
| `product` | 产品方向 |
| `decision` | 需要决策 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
notes：{{notes}}
product：{{product}}
decision：{{decision}}

按任务频率、问题强度、现有流程和采用阻力分组，不凭年龄或职位编造画像。每个分组标注支持记录及缺口，提出最可能受益的早期用户与反例。不要给小样本分组附虚假的总体占比。
```

## 示例输入

```json
{
  "notes": "U1 每天训练模型，用表格记配置；U2 每月实验一次，不愿换工具；U3 管理多人实验。",
  "product": "实验追踪助手",
  "decision": "首批用户选择"
}
```

## 预期输出

证据化用户分组、优先目标与补充访谈问题。

## 适用与边界

适合少量访谈后确定切入点。

样本不具代表性，分组需持续修订。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
