# 只报告可操作的代码问题

[分类目录](README.md) · [总目录](../../README.md)

ID：`coding-agents/review-for-impact`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `diff` | 代码变更 |
| `context` | 使用场景 |
| `review_goal` | 重点 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
diff：{{diff}}
context：{{context}}
review_goal：{{review_goal}}

结合调用路径审查实际会触发的问题，给出具体输入、影响和最小修复建议。区分确定缺陷与待确认假设，引用变更行；不列泛泛风格偏好或无证据风险。若无可操作问题直接说明，不能为凑数量编造发现。
```

## 示例输入

```json
{
  "diff": "新增批量输出逻辑：out_dir / input.name",
  "context": "递归处理多个子目录，可能有同名文件",
  "review_goal": "数据损失与结果覆盖风险"
}
```
