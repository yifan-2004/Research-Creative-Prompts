## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
task：{{task}}
consumers：{{consumers}}
constraints：{{constraints}}

定义请求、响应、错误码、大小与格式校验、超时和版本字段。区分排队时间与模型耗时，说明敏感元数据处理与删除策略如何验证。给出成功及失败 JSON 示例，不泄露内部路径；只做契约设计，不假装服务已部署。
```
