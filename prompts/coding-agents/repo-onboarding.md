## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `tree` | 目录结构 |
| `goal` | 阅读目标 |
| `access` | 可用能力 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
tree：{{tree}}
goal：{{goal}}
access：{{access}}

先根据目录提出待验证的代码路径，然后逐个读取入口、配置解析和数据处理，引用真实文件与行号。区分已确认调用链与推测；不存在的文件不得编造。输出最短阅读路径、运行前未知项和需要进一步读取的位置，遵守只读约束。
```

## 示例输入

```json
{
  "tree": "src/models，src/data，train.py，eval.py，configs/default.yaml",
  "goal": "找到训练入口和图像归一化位置",
  "access": "可只读查看文件，暂不运行或修改"
}
```

## 预期输出

带文件定位的代码地图和阅读顺序。

## 适用与边界

适合代码助手初次接手仓库。

没有文件访问能力时只能规划，不能声称已读。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
