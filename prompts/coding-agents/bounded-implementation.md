# 给 Agent 定义可验收任务

[分类目录](README.md) · [总目录](../../README.md)

ID：`coding-agents/bounded-implementation`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `feature` | 需求 |
| `constraints` | 约束 |
| `acceptance` | 验收 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
feature：{{feature}}
constraints：{{constraints}}
acceptance：{{acceptance}}

先把需求转成输入输出、错误处理、兼容性和验收条件。阅读相关实现后选最小改动，遇到缺失关键信息指出具体阻塞。实施并运行与行为相关的检查，报告改动、验证及未解决问题；不得把未运行的测试写成通过。
```

## 示例输入

```json
{
  "feature": "为图像增强推理添加批量文件夹输入",
  "constraints": "保持原单图接口；只支持 PNG/JPEG；不改模型",
  "acceptance": "输入 3 张图应输出 3 张同名文件，损坏图可报告并继续"
}
```

## 预期输出

实施计划、代码变更和有证据的验证报告。

## 适用与边界

适合授权范围明确的编程 Agent。

实际修改和测试依赖工具能力，提示词本身不执行任务。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
