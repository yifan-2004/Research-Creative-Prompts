# 保持行为的重构计划

[分类目录](README.md) · [总目录](../../README.md)

ID：`coding-agents/safe-refactor`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `code_area` | 目标代码 |
| `contract` | 必须保持 |
| `reason` | 原因 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
code_area：{{code_area}}
contract：{{contract}}
reason：{{reason}}

先记录行为契约和现有调用方，再设计公共函数接口。把语义修复与纯重构分开，使用代表性输入比较重构前后结果。列出浮点容差与边界情况，完成后报告是否出现行为变化；不要顺手升级依赖或修改协议。
```

## 示例输入

```json
{
  "code_area": "训练脚本中重复的指标计算逻辑",
  "contract": "指标公式、聚合方式、输出字段与顺序",
  "reason": "训练与评测脚本实现重复且开始分叉"
}
```

## 预期输出

重构设计、变更与行为一致性证据。

## 适用与边界

适合抽取重复逻辑。

如果原行为含 bug，保持行为与修 bug 需另行决定。
