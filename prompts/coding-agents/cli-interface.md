## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `task` | 工具用途 |
| `users` | 目标用户 |
| `constraints` | 约束 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
task：{{task}}
users：{{users}}
constraints：{{constraints}}

定义必填参数、默认值、互斥关系、退出码与错误信息，保留现有兼容性。给出单图、批量和失败示例，帮助文本要能说明数据与权重要求。不得在缺少权重时默默下载，下载行为必须是明确选项。
```

## 示例输入

```json
{
  "task": "增强单张图或文件夹",
  "users": "熟悉终端的研究生",
  "constraints": "已有 --input、--output；需兼容旧命令"
}
```
