# 从日志生成真实实验日报

[分类目录](README.md) · [总目录](../../README.md)

ID：`coding-agents/experiment-log-agent`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `logs` | 日志摘要 |
| `metadata` | 运行元数据 |
| `audience` | 读者 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
logs：{{logs}}
metadata：{{metadata}}
audience：{{audience}}

区分已完成、运行中、失败和未开始，保留配置与时间定位。只在相同协议和训练阶段可比时比较结果；不能将排队任务写成完成。总结异常、证据和下一步，不对日志没有的数据推断收敛或最终性能。
```

## 示例输入

```json
{
  "logs": "runA 完成 20 epoch，val PSNR 23.2；runB 第 5 epoch OOM；runC 排队",
  "metadata": "A 配置 c1，B 配置 c2，均同数据划分",
  "audience": "研究小组"
}
```

## 预期输出

简洁实验日报、异常表和可执行下一步。

## 适用与边界

适合训练监控与组会材料。

日志可能缺失，需标出信息缺口。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
