# 把复杂目标拆成依赖任务

[分类目录](README.md) · [总目录](../../README.md)

ID：`coding-agents/agent-task-decomposition`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `goal` | 目标 |
| `resources` | 资源 |
| `acceptance` | 总验收 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
goal：{{goal}}
resources：{{resources}}
acceptance：{{acceptance}}

拆出输入契约、推理、评测、展示与集成任务，画依赖关系并标出可并行部分。每项写产物、负责人角色、验收与集成接口，避免两个任务同时修改同一文件。先安排会阻塞全局的未知验证，给出时间不足时的范围收缩。
```

## 示例输入

```json
{
  "goal": "为研究项目增加批量推理、评测和结果网页",
  "resources": "两名开发者，三天，现有单图推理可用",
  "acceptance": "同一配置生成预测、指标与静态展示，来源可追溯"
}
```

## 预期输出

任务图、接口契约、并行分工和集成检查。

## 适用与边界

适合多 Agent 或多人协作。

计划不授权新工具调用，仍需遵守用户原授权。
