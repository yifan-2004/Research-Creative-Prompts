# 设计可删除的助手记忆

[分类目录](README.md) · [总目录](../../README.md)

ID：`coding-agents/personal-assistant-memory`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `use_case` | 用途 |
| `facts` | 候选记忆 |
| `rules` | 用户规则 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
use_case：{{use_case}}
facts：{{facts}}
rules：{{rules}}

逐项判断长期记忆、短期状态或不保存，给出用途、来源、时间与删除条件。不同来源冲突时优先最新明确用户纠正，不将推断当事实。设计查看、更正和删除入口；不得声称已保存，除非实际记忆工具返回成功。
```

## 示例输入

```json
{
  "use_case": "个人科研助手记住课题偏好与近期任务",
  "facts": "偏好中文摘要；本周临时使用 GPU B；会议里出现同事电话",
  "rules": "只存稳定偏好，临时任务七天过期，不记他人敏感信息"
}
```

## 预期输出

记忆候选表、schema 与生命周期规则。

## 适用与边界

适合有持久化记忆的个人助手。

存储行为依赖实际系统，提示词不会自动创建可删除机制。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
