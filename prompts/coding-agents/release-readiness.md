# 研究仓库发布前的验收

[分类目录](README.md) · [总目录](../../README.md)

ID：`coding-agents/release-readiness`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `repo` | 仓库内容 |
| `promise` | 对外承诺 |
| `checks` | 已完成检查 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
repo：{{repo}}
promise：{{promise}}
checks：{{checks}}

对照对外承诺审查依赖、权重、数据、许可证、结果来源和命令。把已验证、未验证和被阻塞的项目分开，建议收窄无法验证的宣传语。重点给能实际执行的最小验收，不把语法通过写成模型可运行，也不擅自上传文件。
```

## 示例输入

```json
{
  "repo": "训练代码、推理代码、README、示例图片，暂不含权重",
  "promise": "能按文档运行推理；当前权重需用户自行提供",
  "checks": "语法检查通过；尚未实际 GPU 推理"
}
```

## 预期输出

发布清单、README 修订建议和真实验证状态。

## 适用与边界

适合 GitHub 仓库公开前。

需文件和运行证据，不能仅据描述认证可用。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
