## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `story` | 故事梗概 |
| `character` | 角色固定特征 |
| `format` | 排布 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
story：{{story}}
character：{{character}}
format：{{format}}

把故事拆成四个单一动作，写每格景别、角色位置、动作和连续性锚点。保证物体位置和动作因果可理解，使用同一角色外观与光线。给出整页提示词和四条单格提示词，避免一格要求多个时间点。
```

## 示例输入

```json
{
  "story": "机器人发现枯萎植物，接水，浇水，看到新芽",
  "character": "橙白机器人，圆脸屏幕，蓝背包",
  "format": "2×2 四格，无对白，横向画布"
}
```

## 预期输出

分镜表、整页提示词与单格版本。

## 适用与边界

适合视觉故事概念稿。

多格生成常有连续性误差，需逐格检查或分开生成。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
