# 建立原创角色设定表

[分类目录](README.md) · [总目录](../../README.md)

ID：`image-generation/character-sheet`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `character` | 原创角色 |
| `views` | 需要视图 |
| `style` | 风格 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
character：{{character}}
views：{{views}}
style：{{style}}

先列不可变外观锚点，再生成多视图设定提示词。要求各视图结构、颜色分区、附件数量与比例一致，避免把不同表情当成不同角色。给出视图排布和每格独立边界，附人工检查的对照项；不借用已有 IP 名称替代原创描述。
```

## 示例输入

```json
{
  "character": "小型橙白机器人，圆屏幕脸，一根短天线，蓝色背包",
  "views": "正面、侧面、背面，等比例",
  "style": "柔和 3D 插画，浅色背景，清晰轮廓"
}
```

## 预期输出

角色锚点表、多视图提示词与一致性检查表。

## 适用与边界

适合原创吉祥物和动画前期。

生成视图可能不严格几何一致，建模前需修正。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
