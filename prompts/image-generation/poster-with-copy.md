## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `event` | 活动信息 |
| `copy` | 逐字文案 |
| `style` | 设计方向 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
event：{{event}}
copy：{{copy}}
style：{{style}}

给出文字层级、对齐、留白与视觉元素，要求逐字使用提供文案，不补主办方、二维码或赞助标识。将海报图像生成与文字校对分为两步；若工具无法可靠排字，提供无字背景方案和后期排版规格。
```

## 示例输入

```json
{
  "event": "夜间视觉研讨会；10 月 20 日 18:00；工程楼 201",
  "copy": "Night Vision Meetup\nOct 20 · 18:00\nEngineering 201",
  "style": "深蓝底、荧光青线条、简洁科技感，竖版 3:4"
}
```

## 预期输出

海报提示词、文字排版规格与逐字检查表。

## 适用与边界

适合活动海报初稿。

图像模型可能拼错文字，正式发布前应逐字校对。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
