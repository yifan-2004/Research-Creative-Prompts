## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `base` | 基础设计 |
| `axes` | 变化维度 |
| `fixed` | 固定条件 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
base：{{base}}
axes：{{axes}}
fixed：{{fixed}}

构建 2×2 变体矩阵，每个变体只改变指定维度。先写共用外观锚点，再生成四条独立提示词与命名规则。要求记录种子或参考图（若工具支持），比较时不把意外变化当成设计选择。
```

## 示例输入

```json
{
  "base": "白色机器人产品主视觉，浅灰背景，三分之二侧视",
  "axes": "光线：冷/暖；镜头：近/远",
  "fixed": "同一外观、材质、产品姿态与画布比例"
}
```

## 预期输出

四条可复制提示词、变量矩阵与比较表。

## 适用与边界

适合系统探索视觉方向。

不同种子仍会改变细节，需人工筛除不受控差异。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
