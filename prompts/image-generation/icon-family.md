## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `icons` | 图标语义 |
| `system` | 风格规则 |
| `background` | 背景 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
icons：{{icons}}
system：{{system}}
background：{{background}}

为每个语义选择最清楚的视觉隐喻，固定画布、留白、描边与圆角规则。给出整组风格提示及单图提示，避免微小不可读细节。说明最终小尺寸检查与需要矢量重绘的部分，不声称生成栅格图可无损缩放。
```

## 示例输入

```json
{
  "icons": "搜索、文档、实验、模型、报告、设置",
  "system": "24px 网格，2px 圆头描边，单色深蓝，统一视觉重量",
  "background": "透明或纯白"
}
```

## 预期输出

图标语义表、共用提示词、六条单图提示。

## 适用与边界

适合产品视觉探索。

正式 UI 应检查小尺寸可读性，精确矢量交付需重绘。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
