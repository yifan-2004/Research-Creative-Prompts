# 只修改参考图指定区域

[分类目录](README.md) · [总目录](../../README.md)

ID：`image-generation/localized-edit`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `reference` | 参考图说明 |
| `edit` | 指定修改 |
| `preserve` | 必须保留 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
reference：{{reference}}
edit：{{edit}}
preserve：{{preserve}}

写成编辑指令：定位目标区域、改变什么、保留什么、边缘与反射如何协调。若没有实际参考图，先指出无法精确编辑而不要虚构看见的内容。禁止顺带美化其他物件；给出并排比较原图与编辑图的核对项。
```

## 示例输入

```json
{
  "reference": "已附图片：桌面上的黑色台灯",
  "edit": "将灯罩换为深绿色磨砂材质",
  "preserve": "灯的形状、底座、桌面、背景、光影和画面比例"
}
```

## 预期输出

精确局部编辑提示词与保留项清单。

## 适用与边界

适合支持图像编辑的工具。

仍可能改动非目标像素；需实际参考图和结果比对。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
