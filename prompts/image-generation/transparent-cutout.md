## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `object` | 主体 |
| `pose` | 姿态 |
| `output` | 输出要求 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
object：{{object}}
pose：{{pose}}
output：{{output}}

强调完整轮廓、附件不裁断、边缘干净和真实 alpha 透明。若工具有 transparent_background 参数，应同时开启；不要把棋盘格画进图片。说明半透明材质与阴影如何处理，生成后检查边缘白边和 alpha 通道。
```

## 示例输入

```json
{
  "object": "一台原创圆角白色小机器人，蓝色眼睛",
  "pose": "正面站立，双手自然下垂，完整全身",
  "output": "透明背景 PNG，主体四周留空，不加文字"
}
```

## 预期输出

生成提示词、工具设置提醒与透明度验收。

## 适用与边界

适合贴纸、图标素材与合成。

仅写“透明”不保证 alpha；需工具支持并检查文件。
