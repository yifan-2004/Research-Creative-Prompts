# 把参考风格拆成可描述元素

[分类目录](README.md) · [总目录](../../README.md)

ID：`image-generation/reference-style-decomposition`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `reference` | 可用参考图或文字 |
| `subject` | 新主题 |
| `constraints` | 限制 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
reference：{{reference}}
subject：{{subject}}
constraints：{{constraints}}

只描述能观察到的配色、线条、材质、光线与空间处理，再给新主题的原创构图。不要臆测作者身份或用在世艺术家姓名替代风格要素。实际图片缺失时依据文字描述并说明。输出能独立理解的生成提示词。
```

## 示例输入

```json
{
  "reference": "参考图：低饱和蓝绿、柔和边缘、纸张颗粒的城市插画",
  "subject": "雨后的大学校园",
  "constraints": "不复制参考构图，不加入作者签名"
}
```

## 预期输出

风格要素表与新构图提示词。

## 适用与边界

适合从参考图提炼一般视觉语言。

不能保证与参考一致，需避免复制独特作品结构。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
