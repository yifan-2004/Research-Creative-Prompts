# 诊断生成图片为何不符合需求

[分类目录](README.md) · [总目录](../../README.md)

ID：`image-generation/image-prompt-diagnosis`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `request` | 原需求 |
| `prompt` | 原提示词 |
| `observed` | 实际问题 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
request：{{request}}
prompt：{{prompt}}
observed：{{observed}}

逐项把需求映射到原提示词，找出冲突、遗漏和过度宽泛描述。提出最小修改版，优先明确主体数量、位置、留白与环境约束；不要堆无关形容词。设计一次只改一个因素的迭代记录，输出可直接重试的提示词。
```

## 示例输入

```json
{
  "request": "产品在右侧，左侧留白，只有一盏灯",
  "prompt": "漂亮的现代台灯，电影级光线，桌面布置丰富",
  "observed": "出现两盏灯，左侧被植物占满"
}
```

## 预期输出

冲突表、修订提示词与下一轮验收标准。

## 适用与边界

适合生成结果反复偏题时。

诊断依据用户观察，未见图时不能评价实际画面。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
