## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `subject` | 人物描述 |
| `setting` | 环境 |
| `mood` | 情绪与风格 |
| `output` | 用途 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
subject：{{subject}}
setting：{{setting}}
mood：{{mood}}
output：{{output}}

生成具体的摄影提示词，描述姿态、视线、镜头距离、光源与背景层次。保持自然皮肤纹理和合理手部，不添加奖牌、校徽或未经提供的身份象征。若使用真实人物参考，强调保留该参考外观并在有权使用的前提下编辑。
```

## 示例输入

```json
{
  "subject": "一位戴圆框眼镜的成年研究者，深蓝衬衫",
  "setting": "安静实验室，背景轻度虚化",
  "mood": "自然专注，纪实摄影，柔和窗光",
  "output": "竖向 4:5，半身，无文字"
}
```

## 预期输出

主提示词与人物一致性检查。

## 适用与边界

适合虚构成年人物或有授权的人像编辑。

无法凭提示词保证身份完全一致；真实人物发布需本人同意。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
