# 生成干净的产品主视觉

[分类目录](README.md) · [总目录](../../README.md)

ID：`image-generation/product-hero`  
状态：**待验证 / untested**

## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `product` | 产品与准确特征 |
| `scene` | 场景 |
| `layout` | 构图与用途 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
product：{{product}}
scene：{{scene}}
layout：{{layout}}

把产品外观、相机角度、材质、光线和构图转换成一段图像生成指令。优先保证产品轮廓与结构，不添加输入未提供的接口、标志或功能。明确留白区域、背景简洁度与接触阴影；附一份生成后核对清单。若要精确保留真实产品，要求提供参考图。
```

## 示例输入

```json
{
  "product": "哑光白色桌面空气传感器，圆角方形，前面一条竖向灯带",
  "scene": "浅灰工作台，自然侧光，无其他设备",
  "layout": "横向 16:9，产品在右侧，左侧留 40% 文案空白"
}
```

## 预期输出

可直接复制的主提示词、可选负面约束与外观核对项。

## 适用与边界

适合产品概念图和宣传草图。

概念图不代表真实产品功能；精确几何与文字需人工复查。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
