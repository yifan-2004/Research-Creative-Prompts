## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `material` | 材质 |
| `scale` | 细节尺度 |
| `requirements` | 贴图要求 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
material：{{material}}
scale：{{scale}}
requirements：{{requirements}}

写清表面微结构、色差范围和排除的大尺度特征。要求无透视、无定向光影与无物体轮廓。附上用 3×3 平铺观察边缘接缝的方法；若需要 PBR 法线或粗糙度图，明确普通彩色图不能自动代表真实物理通道。
```

## 示例输入

```json
{
  "material": "细颗粒浅灰水泥，轻微自然色差",
  "scale": "适合 1 米见方表面，无大裂缝",
  "requirements": "正交正面、均匀照明、四边可平铺、无投影"
}
```
