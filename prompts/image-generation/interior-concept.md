## 输入变量

| 变量 | 填写说明 |
| --- | --- |
| `space` | 空间条件 |
| `needs` | 功能需求 |
| `style` | 风格 |

## 复制模板

将下方变量替换为你的材料。不要将示例中的演示数据用于真实报告。

```text
space：{{space}}
needs：{{needs}}
style：{{style}}

根据空间条件制定一个清楚的机位和功能分区，再写效果图提示词。保持门窗位置与基本动线，说明哪些尺寸只是概念假设。避免生成不可能的悬浮家具或堵塞出口；输出应交给实际平面设计核查的清单。
```

## 示例输入

```json
{
  "space": "20 平方米小型工作室，一面大窗，入口在左前方",
  "needs": "两人办公、拍摄角、封闭储物",
  "style": "浅木、白墙、少量绿植，白天自然光"
}
```

## 预期输出

布局说明、单视角提示词与空间核对项。

## 适用与边界

适合室内设计沟通草图。

不能作为施工图、尺度依据或建筑安全验收。

## 来源与验证

为本合集原创编写，AI 辅助起草；未复制外部提示词。

未经模型运行验证；示例输入用于说明填写方式，不代表已获得输出。
